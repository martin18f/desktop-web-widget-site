Support

Need Help?

If you need help with Desktop Web Widget, send an email with your Windows version, app version, and a short description of the issue.

Before Contacting Support

  • Make sure you are using Windows 10 or Windows 11.
  • Try another website if one page does not load.
  • Use an official embed URL when available.
  • Press Ctrl + Alt + W to enter or exit edit mode.

QR Payment

If you paid by QR code, send the payment confirmation to the support email. The installer and PDF manual will be delivered manually after the payment is confirmed.

Stripe Payment

If you paid through Stripe and did not receive the files, send your Stripe receipt to the support email.
